# 🌿 Tobacco Pest and Disease Diagnosis Expert System

A web-based expert system for detecting and diagnosing pests and diseases in tobacco plants using Knowledge Graphs and Bayesian Networks.

## 🎯 Overview

This system integrates Knowledge Graphs (built with Protégé) and Bayesian Networks with Noisy-OR gates to provide accurate, probabilistic diagnosis of tobacco plant diseases based on observed symptoms.

## ✨ Features

- Intelligent disease diagnosis using Bayesian inference
- Knowledge Graph ontology for structured disease knowledge
- Noisy-OR model for handling symptom combinations
- Interactive web interface built with Streamlit
- Probability-based uncertainty handling

## 🛠️ Tech Stack

- **Python 3.x** - Core language
- **Streamlit** - Web interface
- **Protégé** - Knowledge Graph ontology
- **pgmpy/pomegranate** - Bayesian Network
- **owlready2** - OWL ontology handling
- **Pandas & NumPy** - Data processing
